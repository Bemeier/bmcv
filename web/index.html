What the module is actually saying on MIDI channel 1, at the 7-bit resolution a CC has. The full ±10 V maps onto 0–127, so 0 V is 64 and a channel clamped to a narrower range uses the part of the bar it can reach — a value sitting at either rail is clipping, marked as such. Values are sent only when they change.

Clock is forwarded at 24 PPQN, but only while an input jack is the clock source: when MIDI is the clock, the far end is already the master. Sending needs a MIDI port to send to — the IAC driver on macOS, loopMIDI on Windows, ALSA virmidi on Linux — but the table works without one.

Reset module reboots it, keeping the stored presets. Reset FRAM wipes those and the browser copy. The module autosaves its config to its last preset slot every couple of seconds and the simulator mirrors that into browser storage, so a patch survives a reload.
