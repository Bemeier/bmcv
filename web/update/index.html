Flashes the module over USB-C, from this page.

This browser cannot do it

Flashing needs WebUSB, which only Chromium browsers have.

Chrome, Edge, Opera and Brave work. Firefox and Safari have no WebUSB and no plans for it — there is nothing to enable.

Before you start

Power the module from your case. Its USB-C port is data only, so a cable on its own will not bring it up.

On Windows, once per machine: in update mode the module is a generic ST bootloader Windows has no driver for. Put it in update mode, then in Zadig pick STM32 BOOTLOADER, choose WinUSB, and Replace Driver.

1. Put the module in update mode

Reset from here
Reset by hand
Power the case down, hold CPY, power back up, let go. Works even when the firmware does not — and leaves the panel dark rather than amber, because that is ST's own bootloader running and it knows nothing about the LEDs.

2. Pick a firmware image

A released version
A local build

A raw .bin, written next to the .elf by the build.

3. Flash it

Do not unplug or power down while this runs. An interrupted flash leaves the module in update mode — just flash again. The bootloader is in ROM and cannot be erased.

4. Power-cycle the case

Switch the case off and back on. The firmware is written; this is what starts it.

It will not restart by itself. ST's bootloader drops off USB at the end of an update and waits for a reset nothing can reach it with, so the power cycle is the reset.
