BMCV firmware update

Flashes the module over USB-C, straight from this page.

This browser cannot do it

Flashing needs WebUSB, which only Chromium browsers have.

Chrome, Edge, Opera and Brave all work. Firefox and Safari have no WebUSB and no plans for it, so there is nothing to enable.

Before you start

The module must be powered by your case. Its USB-C port carries data only — VBUS is not connected to anything, so a USB cable alone will not power it up.

On Windows, one-time setup: in update mode the module appears as a generic ST bootloader that Windows has no driver for. Install one with Zadig: plug the module in, put it in update mode below, then in Zadig pick STM32 BOOTLOADER from the list, choose WinUSB as the driver, and hit Replace Driver. You only ever do this once per machine.

1. Put the module in update mode

Two ways in. The first is easier; the second works even if the firmware on the module is too broken to respond.

Connecting asks the browser for the module over USB, so the first time you will be offered a device to pick. The same cable carries the reboot and the firmware that follows it.

From here
By hand
Power the case down, hold FN2, power it back up, then let go.

In update mode the whole panel glows amber — but only if you got there from this page. The FN2 route leaves the panel dark, because at that point the module is running ST's built-in bootloader, which knows nothing about the LEDs. A dark panel there is normal.

2. Pick a firmware image

A released version
A local build

A raw .bin — the build writes one next to the .elf.

3. Flash it

Do not unplug the module or power the case down while this runs. If it is interrupted, the module stays in update mode and you can simply flash again — the bootloader is in ROM and cannot be erased.

4. Power-cycle the case

When the flash finishes, switch the case off and back on. The new firmware is already written; this is just what starts it.

The module will not restart by itself. ST's built-in bootloader disconnects from USB at the end of an update and then waits for a reset that no longer has any way of reaching it, so there is nothing this page can send to bring it back. A power cycle is the reset.
