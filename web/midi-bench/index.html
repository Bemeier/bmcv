USB link diagnostics

Measure the snapshot rate asks for whole module snapshots the way the simulator page does, but decodes nothing and draws nothing. If snapshots are fast here and slow on the simulator page, the transport is fine and the cost is in decoding and drawing them. If they are slow here too, it is the transport or the firmware.

Check WebUSB asks whether this browser can reach the module directly, without going through MIDI at all. Pick the BMCV from the list it offers. If it can claim the module's vendor interface, Windows bound WinUSB to it and the WebUSB route is available.

Nothing is written to the module and nothing is stored. The module streams only while this page keeps asking, so closing the tab stops it.
