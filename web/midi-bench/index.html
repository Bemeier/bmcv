MIDI throughput

Measure the endpoint asks for a burst of — SysEx messages and times them. Each is 48 MIDI bytes, which is exactly one 64-byte transfer, so what comes out is the raw ceiling of the transport.

Measure the snapshot rate runs the real thing instead: it asks for whole module snapshots the way the simulator page does, but decodes nothing and draws nothing. If snapshots are fast here and slow on the simulator page, the transport is fine and the cost is in decoding and drawing them. If they are slow here too, it is the transport or the firmware.

Diagnose the bus asks nothing and assumes nothing: it opens every port, reports its state, sends one identity request to each output, and prints every byte that comes back. Use it when a module that is plainly there answers nothing.

Nothing is written to the module and nothing is stored. The burst is bounded in the firmware, so closing this tab stops it.
