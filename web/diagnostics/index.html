Diagnostics

Measure the snapshot rate asks for whole module snapshots the way the simulator page does, but decodes nothing and draws nothing. If snapshots are fast here and slow on the simulator page, the transport is fine and the cost is in decoding and drawing them. If they are slow here too, it is the transport or the firmware.

Inspect the device reports what this browser can see of the module: its interfaces and endpoints, whether the vendor interface can be claimed - which is what says the driver bound correctly - and what firmware it is running. Pick the BMCV from the list it offers.

Nothing here changes the module: no reset, no stored preset touched, nothing written but requests for what it is already doing. The module streams only while this page keeps asking, so closing the tab stops it.
