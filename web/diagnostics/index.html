Instruments for the link between this browser and a module.

What this browser can see

Inspect the device lists the module's interfaces and endpoints, whether the vendor interface can be claimed - which is what says the driver bound - and what firmware it runs.

Measure the snapshot rate streams snapshots and decodes nothing. Fast here and slow on the simulator means the cost is in drawing them; slow here too means the transport or the firmware.

starting up

Nothing here changes the module, and it streams only while this page asks.

Send a MIDI clock

Clocks the module from this browser, over the MIDI half of the same cable. 24 clocks to the beat, scheduled ahead through Web MIDI rather than fired from a timer, so what the module measures is the tempo asked for and not this tab's jitter.

Set every input to — under SYS first. A patched clock always wins over one that is not even physical, so with a jack still in CLOCK mode this does nothing and looks broken. Watch bpm in and bpm run on the simulator.
